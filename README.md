### 👨‍💻 Perfil Profesional

Desarrollador **Full Stack** en **AION CLOUD**, especializado en el diseño e implementación de aplicaciones web de extremo a extremo. Mi enfoque combina arquitecturas backend escalables y seguras con interfaces de usuario limpias, responsivas y orientadas a la experiencia del usuario.

Cuento con una base sólida en el ecosistema **Java** (**Spring Boot**, **Hibernate**, **MySQL**) y desarrollo frontend moderno con **React** y **Angular**. Priorizo la calidad del software mediante pruebas unitarias automatizadas, control de versiones estricto con **Git** y despliegue en entornos contenerizados con **Docker**.
